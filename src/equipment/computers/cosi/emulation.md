# Emulation

As the name implies, Emulation is intended to be used for game emulation, although at present it serves more as a gaming PC. While it originally had hardware near-identical to [Presenter](./presenter.md) and [Fridge](./fridge.md), it was upgraded in Spring 2026 to its current configuration.

## Notes

Emulation's motherboard required a BIOS update to recognize the 5700X, and in doing so the onboard ethernet appears to no longer work. As such, Emulation utilizes a USB to RJ45 adapter to connect to the COSI ethernet.
