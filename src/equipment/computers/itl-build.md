# ITL Build

Since the ITL has been used as a lab and a classroom, it will need to have any software professors teaching in there require. Rebuilds are common to happen (usually once or twice a year).

The ITL machines currently run Fedora 44 and Windows. The Windows installs are manged by OIT, but the Linux installs are managed by COSI. For fleet management, we use a collection of ansible playbooks that can be found on our [GitLab](https://git.cosi.clarkson.edu/cosi-meta/itl-scripts/).
