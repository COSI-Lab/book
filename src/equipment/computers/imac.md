# Hacked-up Linux iMac

In Spring 2023, at the Bonus Meeting, Nate Wilson donated an EOL iMac running a completely-fine modern 2023 Linux! Despite being destined for a landfill, this workstation is now configured in the "placard corner" near the glass window door.

This machine currently displays [slides.cosi.clarkson.edu](https://slides.cosi.clarkson.edu).
