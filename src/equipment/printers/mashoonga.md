# Mashoonga
Mashoonga is an HP LaserJet P3015 located near the presenter computer. It can print in black and white.

You can print to Mashoonga by using it's web interface or by configuring it as a printer in your system settings. 
Mashoonga supports bonjour (Avahi) discovery. You should ideally not use the web interface because it has been 
known to not play nice with modern PDFs (see "Juno's Last Straw").

**Mashoonga has been known to emit smoke. This is normal. Please disregard the smoke unless acompanied by fire.**
