# Phones
In the past COSI has run their own IP phone system, however this is no longer the case. The phones in COSI and the ITL are both managed by OIT. Both phones have DID numbers under Clarkson's prefix, which you can find by calling yourself and checking the caller ID. These phones can also dial internal Clarkson extensions. 

There may have historicaly been a phone in 2nd floor, however it's line is currently disconnected.
